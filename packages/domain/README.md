# Shared anchoring assessment

`@anchor-buddy/domain` is a pure TypeScript package used unchanged by the mobile app and API. Input and output values are JSON serializable. It uses metres, knots, true degrees, UTC ISO instants, and `[longitude, latitude]` coordinates. `validateVessel`, `validateSearch`, and `validateRegionPack` return arrays of errors; an empty array means the input structure is valid, not that maritime evidence is sufficient.

For current use, call `assessCandidate(candidate, vessel, search, pack, context)` or `searchRegion(pack, vessel, search, options, context)` with `context = { assessedAt: explicitIsoTimestamp, purpose: 'current' }`. Supply the clock freshly from the server or app minute/resume update, not from a stored search preference. Results echo `context`. Current assessments downgrade elapsed stays (including departure contingency), currently expired evidence and future-dated evidence to insufficient evidence; existing exclusions remain excluded. The engine never reads the wall clock implicitly. Omitting context preserves deterministic historical replay and returns `context: null`; explicit `purpose: 'historical'` also preserves historical validity regardless of today's date. Historical outcomes do not certify current conditions. An already armed native watch remains independent of assessment freshness.

When reassessing a selected deeper search alternative, pass its `depthAllowancePercent` as the optional sixth argument to `assessCandidate`. Only `0`, `20` and `30` are accepted; omission means the original preferred depth. This preserves the explicit alternative label and relaxes only preferred depth, never equipment, clearance, weather or permissions.

The shipped Florida Keys fixture is **entirely synthetic**. Its official-source URL is a future ingestion reference, not a claim that these artificial depths, places, forecasts or fees came from NOAA. Every assessment includes `simulated`, and live data cannot pass until region review, evidence provenance and equipment guidance are established.

The engine uses lower depth bounds for under-keel clearance and upper bounds plus bounded water levels for required rode. It repeatedly expands the footprint when deeper intersecting areas require more rode. The circle includes the greater of required and explicitly deployed rode, vessel length, half beam and the user's safety margin. All wind directions share that full circle. No rendered chart tiles or interpolated point soundings enter these checks.

Geometry deliberately favors false negatives over invented coverage. Polygon holes and any enclosed tiny hazard are evaluated. A single unsimplified depth/coverage polygon must prove full disk containment: adjacent chart features are not silently unioned, and unresolved chart seams return insufficient evidence. Production ingestion should validate and dissolve compatible, same-datum coverage regions while retaining unsimplified hazard and depth boundaries. GeoJSON segments are densified at 100 metres in an anchor-centred equidistant projection, with a two-metre conservative geometry guard. This regional method needs maritime/geospatial review before use outside the intended region.

Forecast and water-level intervals must cover arrival through departure contingency. Every interval must cite `coverageAreaIds`: weather intervals need weather and current areas, and tide intervals need the area of their reviewed station relationship. Each linked area must cover the whole footprint and applicable interval. Unrelated regional coverage cannot make a remote station or grid cell applicable. Coverage for hazards, habitat, restrictions, bathymetry, tides, current and weather must be explicitly positive. Empty polygons do not prove absence. Restriction applicability must be resolved by jurisdiction/date. All anchor positions, including documented anchorages, need reviewed equipment-compatible holding evidence. Missing information never becomes a reassuring default.

Tariffs define night as local calendar nights (at least one), day as each occupied local calendar date, and hour as commenced elapsed hours. Seasonal bands are inclusive local dates and must be unambiguous. Length minimums and per-period charge minima apply before multihull/beam supplements, then a stay minimum, required extras and taxes. Optional extras remain excluded and named. Different currencies are grouped without invented conversion rates. These conventions must match each operator's published rules before ingesting their tariff.

Run `npm run test --workspace=@anchor-buddy/domain` and `npm run typecheck --workspace=@anchor-buddy/domain`. Tests replay identical JSON inputs through the same portable engine; they do not substitute for actual iOS/Android runtime or on-water validation.
