### Open advisory disposition

GHSA-g3hv-75wg-m249 remains under `expo@58.0.24 → @expo/fingerprint@0.21.10 → minimatch@10.2.6`. npm also reports Expo and MapLibre React Native through that dependency and peer path. The advisory requires an attacker-controlled pattern and minimatch optimization level 2 or higher. Expo fingerprint passes `{dot: true}` in its ignore-path helpers, and minimatch defaults to level 1. No repo fingerprint ignore configuration or API/app path invoking the affected code was found.

The dependency maintainer owns reassessment on 2026-11-25 or at the next Expo 58 patch, whichever comes first. The finding remains visible and is nonblocking for this local verification tranche given the observed call path. Reassess before distribution if Expo's input or optimization options change. No override was used. npm's suggested older Expo/MapLibre combinations fall outside the current supported app stack.
