## Acceptance criteria

1. Error text is associated with the input and announced together with label/unit/help.
2. Required, disabled, zero and empty values retain their existing meanings.
3. Form owners can focus the first invalid field without querying internal DOM structure.
4. Unrecognized domain errors remain visible in a form-level summary rather than being dropped.
