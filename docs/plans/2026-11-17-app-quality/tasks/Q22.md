## Implement

## Acceptance criteria

1. Missing currency never silently renders as USD; malformed currency does not crash.
2. JPY/USD/KWD display 0/2/3 fractional digits under the documented legacy policy; this does not claim to reconstruct source precision.
3. Zero is called Free only when the existing estimate state supports that conclusion.
4. Cards, details and saved snapshots render the same known estimate consistently; legacy snapshots lacking fee status do not call an unverified zero Free.
