## Observed gap

Both chart implementations independently take the first 50 results and assign rank by array position. Selection styling replaces status color, and the selected map card loses status context.

## Implement

Derive a shared display model for rank/status/selection and make the first-50 boundary explicit. Preserve status when selected and keep manual pins separate.

## Acceptance criteria

1. Filtering/sorting produces identical visible rank and selected identity in map/list.
2. Selecting a list item beyond the marker limit either reveals it explicitly or explains its absence; it never highlights another place.
3. Selected markers retain human-readable status; manual pins are not added to source-result counts.
4. A compact legend explains marker/selection symbols without implying nautical coverage.
